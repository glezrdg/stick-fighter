# Stick Fighter

Beat'em up 2D en HTML5/Canvas con stickman articulado. Espada + arco, combos de 6 ataques con auto-aim, 9 tipos de enemigos, oleadas, gore/desmembramiento, 13 skins.

## Cómo correrlo

Abre `index.html` directamente con el navegador (doble click). No requiere build ni servidor.

## Controles

- **WASD / flechas** — mover
- **ESPACIO** — espada (combo de 6 ataques con auto-aim)
- **F** — disparar arco
- **Q / E** — habilidades equipadas
- **Doble tap** — dash (si la skill está desbloqueada)

## Deploy

Configurado para Vercel (`vercel.json` con `cleanUrls`). Es un sitio estático: cualquier host de archivos estáticos sirve.
